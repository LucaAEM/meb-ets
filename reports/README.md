# Curated result summaries

These CSV tables were extracted from the supplied simulation report, empirical collector report and final empirical diagnostics report. Table contents were not recomputed, rounded or edited. The extraction manifest identifies source reports by SHA-256 and records each extracted CSV checksum. Files are UTF-8.

The deposit deliberately excludes source data snapshots, horizon-level actual outcomes, full fit checkpoints and manuscript/reviewer correspondence. It is a collection of reported summaries, not a complete set of inputs for rerunning the original checkpoint audits.

Simulation primary pairwise contrasts use available pairs; complete-panel tables use their explicitly reported common supports. BLD failures remain visible. Simulation Holm columns are exploratory sensitivities. Empirical t intervals for mean contrasts must not be described as bootstrap intervals; bootstrap coverage intervals concern a different quantity. Flag subsets are descriptive and do not replace the primary comparisons. Grid perturbations are hypothetical criterion sensitivity, not corrected fits. Future-path sensitivity uses finite nested prefixes, not exact quantiles.

Fitting and audit scripts, usage instructions, and a final replication release remain to be added. Do not infer public-release readiness from this deposit alone.
